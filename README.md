# Kreature

SPA local-first para controle de lançamentos, instituições, investimentos, planejamento, importação e Perfil Kreature.

## Executar

```bash
npm install
npm run dev
```

## Verificar

```bash
npm test
npm run build
npm run lint
```

Os dados ficam no IndexedDB do navegador. Não há autenticação, sincronização, Open Finance ou envio de extratos para servidores. CSV, XLS/XLSX e PDFs pesquisáveis são processados localmente. Cotações externas são opcionais e sempre possuem alternativa manual.
